    How Situation Guard works

    Alexa listens and proposes. A strict engine decides. You approve.

    • A plan is a set of commitments — who does what, when, where, with which shared things (a TV, a room), and what matters most.
    • The engine checks rules — one person can’t be in two places, a shared TV fits one show, a deadline is a deadline, nothing happens in the past, a closed or rained-out place can’t be used.
    • Reality comes in — delays, cancellations, weather, public holidays, your calendar.
    • Fixes are tested before they are offered — Alexa only says an option works if the engine said so, and changes the plan only after your yes, then re-checks it.

    Every action is an MCP tool call to the Situation Guard server, the same way Alexa+ or any MCP client would use it.
